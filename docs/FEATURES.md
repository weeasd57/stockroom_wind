# Features

- Social Trading Posts: rich content, images, symbols, strategies
- Community Interaction: likes, comments, follows, profiles
- Stock Information & Search: global markets with country flags, exchange mapping
- Authentication & Profiles: Supabase Auth with profile management
- Pro Subscription: PayPal checkout, webhook handling, subscription records
- Premium Broker Plans: subscribe/unsubscribe flow, UI badges
- Telegram Integration: bot webhook for subscriptions, broadcast endpoints, contact bridge
- Background Processes: unified drawer for tasks, progress feedback
- Performance Optimizations: throttled fetch/logging, memoization
- Theming & Responsiveness: light/dark themes, modern UI, mobile friendly
- Export: Table view with CSV export
