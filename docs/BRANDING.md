# Branding & Customization

## Name & Text
- Project name is `sharkszone`. Update textual references in UI as needed.

## Logo
- Place your logo at `public/images/logo.png`.
- Update favicon files in `public/` if desired.

## Colors & Theme
- The app uses CSS Modules and theme variables. Search in `src/styles/` and `src/app/globals.css`.

## Images & Allowed Domains
- Update `next.config.js` `images.domains` to add any new asset hosts.

## Strings & Copy
- Search and replace brand mentions in components under `src/components/` and pages under `src/app/`.
